# Knowledge-Sharing Catchup

Run a series of one-to-one conversations with people doing the work, in any field — ask the same good questions each time, file the notes, and turn it all into summaries you can learn from.

## What it does

- Helps you write your own set of 10 questions for your field
- Creates the calendar meeting and a call sheet before each catchup, with a professional intro script personalised with the person's name
- Files rough notes under the right question while you talk, and writes a summary after each meeting
- About an hour after a call ends, asks you whether it happened — and only then asks about a transcript
- Fills the questionnaire from a transcript three ways: fetched from Fathom, pasted or uploaded in chat, or uploaded on the person's page with an "Answer from transcripts" button — only where the transcript clearly says so, shown to you first, saved only after you approve
- Writes one all-meetings summary at the end: themes, agreements, disagreements, tools, and what it means for your learning

## Files

- `knowledge-sharing-catchup-skill.md` — the skill itself
- `skill.yaml` — the skill's name and description
- `how-to-install.md` — how to install and start using it
- `what-is-it-about.md` — the plain-language explainer
- `knowledge-sharing-catchup-claude-version.md` — the same system rebuilt for Claude

## Privacy

Each person gets their own private copy. Your meetings, notes, answers, and transcripts stay with you — sharing the skill gives someone the same system, not your conversations.
